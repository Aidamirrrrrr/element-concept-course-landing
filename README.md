# Element Concept — лендинг курса «Интерьерная флористика»

Одностраничный лендинг курса студии Element Concept. Статика без фреймворков:
HTML, CSS и один файл скрипта.

**Демо:** https://aidamirrrrrr.github.io/element-concept-course-landing/

Lighthouse (мобильный профиль): **производительность 100 · доступность 100 ·
лучшие практики 100 · SEO 100**.

## О курсе (контент страницы)

4 занятия по 2,5—3 часа · 1 месяц, по воскресеньям · группа 6—8 человек · 60 000 ₽.
В стоимость входят цветы и вазы для практики, рабочая тетрадь с ручками,
презентация к каждому уроку и подборка «чем вдохновляться».

## Запуск и сборка

```bash
python3 tools/serve.py 4321
```

Исходники открываются на http://localhost:4321 — сервер отдаёт файлы без
кэширования и с gzip, как боевой хостинг.

```bash
python3 tools/build.py
```

Собирает `docs/` — именно оттуда GitHub Pages отдаёт сайт. Сборка встраивает
стили и скрипт прямо в HTML: у страницы не остаётся ни одного блокирующего
отрисовку запроса. Посмотреть результат: `python3 tools/serve.py 4322 docs`.

## Структура

```
index.html                  разметка и SEO (Open Graph, JSON-LD: Course + FAQPage)
css/style.css               стили и вся декларативная анимация
css/fonts.css               генерируется tools/build-fonts.py — не править руками
js/app.js                   разбивка заголовков, появления, параллакс, барабаны цифр
fonts/                      5 подрезанных начертаний woff2 (63 КБ на всё)
img/ph/                     SVG-плейсхолдеры под фотосъёмку
docs/                       собранная версия для GitHub Pages
tools/build.py              сборка docs/
tools/build-fonts.py        сборка и подрезка шрифтов
tools/gen-placeholders.py   генератор плейсхолдеров
tools/serve.py              локальный сервер (no-cache + gzip)
```

## Шрифты

Google отдаёт вариативные шрифты, разрезанные по `unicode-range`: 10 файлов и
207 КБ. Первый экран при этом ждал минимум два запроса — кириллицу для
заголовка и латиницу для логотипа и цифр, — и Lighthouse привязывал к ним FCP.

`tools/build-fonts.py` качает исходные TTF из репозитория google/fonts,
вырезает статичное начертание нужного веса из вариативного шрифта и подрезает
его под символы страницы плюс страховочный набор (вся русская азбука,
латиница, цифры, пунктуация). Итог — 5 файлов и 63 КБ.

```bash
python3 -m venv .venv && .venv/bin/pip install fonttools brotli
.venv/bin/python tools/build-fonts.py
```

Запускать, если сильно поменялись тексты (например, появился новый язык).
Исходные TTF кэшируются в `fonts/src/` и в репозиторий не попадают.

## Плейсхолдеры

Все кадры — временные SVG: на каждом номер слота, что снимать и рекомендованный
размер. Список слотов и подписи лежат в `tools/gen-placeholders.py`:

```bash
python3 tools/gen-placeholders.py
```

Заменить на съёмку — положить файлы в `img/`, поправить `src` и `alt`
у соответствующих `<img>` в `index.html`, пересобрать `docs/`.

## Анимация

Появления и счётчики ведёт IntersectionObserver, прокрутку — один общий
rAF-цикл (геометрия читается пачкой, стили пишутся пачкой, без forced reflow).
Полосу прогресса, где браузер умеет, ведёт CSS scroll-таймлайн — без скрипта.

Что происходит на странице: шторка прелоадера, посимвольный выезд заголовков
из масок, шторки кадров (снизу и сбоку), параллакс изображений, подсветка
цитаты по мере прокрутки, счётчики, барабаны разрядов в цене, бегущая строка
с реакцией на скорость прокрутки, наклон блока по инерции, наклон карточек за
указателем, липкая стопка карточек уроков, магнитные кнопки, прячущаяся шапка.

Всё выключается при `prefers-reduced-motion: reduce`; есть режим
`prefers-contrast: more` и стили для печати.

## Что нужно дописать перед боевым запуском

- Фотографии вместо плейсхолдеров.
- Блок «Кто ведёт»: имя преподавателя и опыт (в разметке помечен `<mark>`).
- Даты воскресений и адрес студии.
- Ссылки на Telegram и Instagram в подвале.
- Обработчик формы заявки — сейчас `onsubmit="return false"`.
- Домен в `canonical`, `og:url`, JSON-LD и `tools/build.py`, если сайт
  переедет с GitHub Pages.
