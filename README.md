# Element Concept — лендинг курса «Интерьерная флористика»

Одностраничный мокап лендинга курса студии Element Concept.
Статика без сборки: HTML, CSS и один файл скрипта.

**Демо:** https://aidamirrrrrr.github.io/element-concept-course-landing/

## О курсе (контент страницы)

4 занятия по 2,5—3 часа · 1 месяц, по воскресеньям · группа 6—8 человек · 60 000 ₽.
В стоимость входят цветы и вазы для практики, рабочая тетрадь с ручками,
презентация к каждому уроку и подборка «чем вдохновляться».

## Запуск

```bash
python3 tools/serve.py 4321
```

Сервер отдаёт файлы без кэширования — правки в `css/` и `js/` видно с первой
перезагрузки. Открыть: http://localhost:4321

## Структура

```
index.html                 разметка и SEO (Open Graph, JSON-LD: Course + FAQPage)
css/style.css              стили и вся декларативная анимация
css/fonts.css              локальные @font-face
js/app.js                  разбивка заголовков, появления, параллакс, счётчики
fonts/                     Manrope, Literata, IBM Plex Mono (woff2, кириллица + латиница)
img/ph/                    SVG-плейсхолдеры под фотосъёмку
tools/gen-placeholders.py  генератор плейсхолдеров
tools/serve.py             локальный статик-сервер
```

## Плейсхолдеры

Все кадры — временные SVG: на каждом написан номер слота, назначение и
рекомендованный размер. Список слотов и подписи лежат в
`tools/gen-placeholders.py`; после правки списка:

```bash
python3 tools/gen-placeholders.py
```

Заменить на съёмку — положить файлы в `img/` и поправить `src` и `alt`
у соответствующих `<img>` в `index.html`.

## Что нужно дописать перед боевым запуском

- Фотографии вместо плейсхолдеров.
- Блок «Кто ведёт»: имя преподавателя и опыт (в разметке помечен `<mark>`).
- Даты воскресений и адрес студии.
- Ссылки на Telegram и Instagram в подвале.
- Обработчик формы заявки — сейчас `onsubmit="return false"`.
- Домен в `canonical`, `og:url` и JSON-LD, если страница переедет с GitHub Pages.

## Анимация

Движение построено на IntersectionObserver и одном общем rAF-цикле:
появление блоков, посимвольная разбивка заголовков, параллакс кадров,
подсветка текста по прокрутке, счётчики, бегущая строка и наклон по инерции.
Всё выключается при `prefers-reduced-motion: reduce`.
